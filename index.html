BradyPus

Plataforma de estudos adaptativa para concursos, ENEM, vestibular, OAB e idiomas. Trilhas de conteúdo geradas de forma totalmente autônoma por agentes de IA orquestrados via LangGraph, com RAG (Retrieval-Augmented Generation) sobre banco vetorial ChromaDB para embasar o conteúdo gerado. Inclui banco de questões ilimitado, revisão espaçada e extensão de navegador para foco. Coautoria no desenvolvimento.

Instagram: @bradypusapp

SpotyTube

Extensão do Chrome que abre o videoclipe oficial da música tocando no Spotify e mantém o vídeo sincronizado com o player, e também no sentido inverso. JavaScript puro sobre Manifest V3, sem build, com OAuth PKCE, Spotify Web API e ranking próprio para escolher o clipe certo.
